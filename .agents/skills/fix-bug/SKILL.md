# Skill: fix-bug
# 트리거: "버그", "에러", "안 돼", "고쳐줘", "문제가"

## 버그 수정 패턴 (바로 고치지 않는다)

### Step 1: 재현 먼저
```
1. 에러 메시지 전체 읽기
2. 재현 경로 파악 (어떤 액션 → 어떤 에러)
3. 관련 파일 특정 (src/ 범위 좁히기)
```

### Step 2: 원인 가설 (수정 전 공유)
```
1. 재현 경로
2. 원인 가설 (최대 3개)
3. 수정 예상 범위 (파일 목록)
4. 회귀 테스트 계획

→ 사람 확인 후 수정 시작
```

### Step 3: 최소 수정
```
- 가장 단순한 수정 우선
- 전체 파일 재작성 금지
- 변경 범위 최소화
```

### Step 4: 재발 방지
```
1. 수정 완료 후 재발 방지 테스트 추가
2. AGENTS.md에 방지 규칙 1줄 추가
   형식: # [날짜] — 무엇이 잘못됐는가 → 앞으로 어떻게
```

## 에러 반복 시 에스컬레이션
- 동일 에러 3회 실패 → 다른 접근법
- 5회 실패 → 중단하고 사람에게 보고
- 같은 파일 5회 이상 수정 → 설계 재검토 요청
