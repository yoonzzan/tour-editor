## 1. 화면 구성 개요

```
[하나투어 기존 시스템 — 견적서 상세 화면]
  ┌──────────────────────────────────────────────────────┐
  │ 견적 [ QC00687628001 ]   청발 장가계 5일             │
  │ 작성자: 조유미 / 답변자1: 한상일 / 담당세일즈: ...   │
  │                                    [에디터 열기] ◀── │ ← 이 버튼
  └──────────────────────────────────────────────────────┘
       │ window.open('/editor/popup?quoteNo=QC00687628001&role=agent')
       ▼
  ┌──────────────────────────────────────────────────────┐
  │  견적 에디터 팝업 (1280×900px)                       │
  │  [하나투어 로고] [QC00687628001 · 청발 장가계 5일]   │
  │  [ver: v1.0]  [저장]  [미리보기]  [Excel▼]  [닫기] │
  ├──────────────────────────────────────────────────────┤
  │  [일정표 탭]  [견적서 탭]                            │
  │  ...편집 영역...                                     │

       ▼
  [부모 창 자동 새로고침]
```

## 2. F-00 팝업 진입 및 초기화

### FD-POPUP-01 진입 파라미터 처리

에디터는 독립적으로 접근할 수 없고, 반드시 기존 견적서 상세 화면에서 팝업으로 실행된다.

**URL 형식**
```
/editor/popup?quoteNo=QC00687628001&role=agent
```

**초기화 흐름**
```
1. URL 파라미터에서 quoteNo, role 추출
2. 미로그인 상태면 /login?callbackUrl=현재 팝업 URL로 이동하고, 로그인 후 원래 팝업 URL로 복귀
3. 세션 role과 URL role이 다르면 권한 없음 화면 표시
4. quoteNo로 기존 견적 데이터 및 최신 버전 조회
   └ 견적이 없으면: 빈 에디터 표시 + "검색 팝업" 자동 오픈
   └ 견적이 있으면: 최신 버전 데이터 에디터에 로드
5. Quote의 Bid 배정 UserID(partnerId/agentId/salesId)와 현재 UserID 매칭 검증
6. role에 따라 UI 권한 분기 적용
7. 에디터 렌더링 완료
```

**파라미터 검증**
| 파라미터 | 유효성 검사 | 오류 처리 |
|---------|------------|-----------|
| quoteNo | 필수, 영숫자 | 없으면 "잘못된 접근입니다" 에러 페이지 |
| role | partner / agent / sales 중 하나 | 세션 role과 다르면 권한 없음 |

### FD-POPUP-02 팝업 윈도우 동작

| 항목 | 사양 |
|------|------|
| 창 크기 | 1280 × 900px (기본), 사용자 리사이즈 가능 |
| 위치 | 화면 중앙 |
| 닫기 | X 버튼 또는 [닫기] 버튼 |
| 미저장 닫기 | "저장하지 않고 닫으시겠습니까?" 확인 다이얼로그 |
| 저장 후 통신 | `window.opener.postMessage({ type: 'SAVE_COMPLETE', quoteNo: '...', versionNo: 'v1.1' }, '*')` |

## 3. 공통 기능

### FD-COMMON-01 자동 임시 저장
- **동작**: 에디터 편집 중 30초마다 로컬스토리지에 자동 저장
- **표시**: 화면 우상단에 "자동 저장됨 HH:MM" 표시
- **복원**: 에디터 재진입 시 미저장 임시 데이터 감지 → "이전에 저장하지 않은 내용이 있습니다. 불러올까요?" 팝업

| 항목 | 내용 |
|------|------|
| 저장 주기 | 30초 |
| 저장 위치 | `localStorage['draft_${quoteId}']` |
| 만료 시간 | 7일 (그 이후 자동 삭제) |
| 충돌 처리 | 저장 API 호출 시 `expectedVersion`으로 최신 버전 검증, 불일치 시 409 충돌 안내 |

### FD-COMMON-02 저장 버튼
- **위치**: 에디터 상단 고정 헤더
- **동작**: 클릭 → 변경 사유 모달 → 확인 → 새 버전 생성 API 호출
- **상태 표시**:
  - 변경 없음: "저장" 버튼 회색 비활성
  - 변경 있음: "저장" 버튼 파란색 활성 + 상단에 "저장되지 않은 변경사항이 있습니다" 배너
  - 저장 중: 버튼 로딩 스피너 + 비활성
  - 저장 완료: "v1.1 저장됨" 토스트 메시지 (3초 후 자동 사라짐)
  - 저장 실패: "저장 실패. 다시 시도하거나 임시 저장 내용을 확인하세요." 에러 메시지

### FD-COMMON-03 변경 사유 입력 모달
- **트리거**: 저장 버튼 클릭 시
- **구성**:
  - 텍스트 입력창 (placeholder: "변경 사유를 입력하세요 (선택)")
  - `확인` / `취소` 버튼
- **동작**: 빈 값으로 확인해도 저장 진행. 취소 시 편집 상태 유지.

### FD-COMMON-04 상단 헤더 공통 정보 표시
```
[하나투어 로고] [상품명 + 비딩코드]           [ver: v1.2] [저장] [미리보기] [Excel▼]
```

> **로고 파일**: `docs/하나투어-로고_국문CMYK_풀컬러-가로형.png` (fallback: `public/images/hanatour-logo.png`)
> - UI 표시: `<Image src="/images/hanatour-logo.png" alt="하나투어" />`
> - Excel 삽입: `worksheet.addImage(workbook.addImage({ filename: resolveLogoPath(), extension: 'png' }), ...)`

## 4. F-01 검색 및 불러오기 팝업

### FD-SEARCH-01 팝업 진입
- **트리거**: 에디터 최초 진입 시 자동 표시 (신규 견적) OR 헤더의 "데이터 불러오기" 버튼 클릭
- **탭 구성**: `상품코드 입력` / `파일 첨부` / `직접 입력`
  - ~~`패키지 검색`~~ → **2차**
  - ~~`내 견적`~~ → **2차**

### FD-SEARCH-02 상품코드 입력 탭 (MCP 연동) 

**동작 흐름**
```
사용자가 상품코드 입력 (예: S22C-7i)
    │
    └→ MCP: 하나투어 상품 데이터 조회
         └→ 결과 있음: 상품명 + 일정 미리보기 표시
         └→ 결과 없음: "상품코드를 찾을 수 없습니다" 안내
```

**입력 UI**

| 요소 | 설명 |
|------|------|
| 텍스트 입력창 | 상품코드 입력 (실시간 자동완성) |
| 검색 버튼 | MCP 호출 트리거 |
| 로딩 인디케이터 | MCP 응답 대기 중 표시 |

**결과 표시**
- 상품명, 지역, 기간, 일자별 주요 일정 요약 미리보기
- "이 일정으로 시작하기" 버튼
- 불러오기 옵션: `전체 교체` / `일자 선택 후 합치기`

**MCP 연동 명세**
```typescript
// MCP: 하나투어 상품 데이터
// Tool: search_product_by_code
// Input: { productCode: string }
// Output: { productName, region, duration, itinerary: DaySchedule[] }
```

### FD-SEARCH-03 파일 첨부 탭
- 파일 드래그앤드롭 또는 파일 선택 버튼
- 지원 형식: `.xlsx`, `.pdf`, `.hwpx`
- 미지원 형식: `.xls`는 .xlsx 변환 안내, `.hwp`는 .hwpx 또는 PDF 변환 안내
- 용량 제한: 10MB
- 파싱 결과 미리보기 후 확인
- 파싱 방식:
  - PDF는 `pdf-parse` 텍스트 추출을 우선 사용하고, 추출 텍스트가 부족한 이미지형 PDF는 페이지 이미지 OCR fallback을 수행
  - AI 파서 후보와 기본 표 파서 후보를 모두 생성
  - PDF OCR 결과도 원문 텍스트로 취급해 동일한 AI/기본 표 파서 품질 비교를 수행
  - 표 형태 입력은 원문 셀 경계와 파일 입력 순서를 우선 보존
  - 식사 열의 `조:`, `중:`, `석:`, `조식:`, `중식:`, `석식:` 값은 식사 항목의 권위값으로 보정
  - `HOTEL`, `숙소`, `숙 소`, `호텔 투숙` 등 숙박 표기는 숙박 항목으로 보정
  - AI 결과가 품질 기준을 통과하지 못하거나 기본 표 파서가 더 안정적이면 기본 표 파서 결과와 진단 메시지를 표시

### FD-SEARCH-04 직접 입력 탭
- 텍스트 영역에 일정을 자유롭게 붙여넣기
- "붙여넣기 후 자동 파싱 시도" 버튼
- 파싱 실패 시 빈 에디터에서 수동 입력으로 진행

### FD-ITIN-05 일자별 블록 — 다중 항목 구조

**블록 헤더**: `제 N 일` + `YYYY-MM-DD (요일)` + `지역명`

**핵심 구조**: 동일 일차에 **동일 구분의 항목이 여러 개** 존재할 수 있다.

```
[제 1 일]  2026-12-02 (목)  싱가포르
  ┌─────────────────────────────────────┐
  │ [이동]   전용버스               [⋮] │  ← 드래그 핸들
  │ [관광]   센토사섬               [⋮] │  ← 관광 1
  │ [관광]   국립식물원             [⋮] │  ← 관광 2 (동일 구분 가능)
  │ [관광]   스카이파크             [⋮] │  ← 관광 3
  │ [식사]   조식X / 중식 현지식   [⋮] │
  │ [숙박]   메리어트 말라카  ← 자동 고정 (이동 불가) │
  └─────────────────────────────────────┘
  [+ 항목 추가]
```

**항목 추가 방식**: 블록 내 `+ 항목 추가` 버튼 클릭 → 항목 유형 선택 → 해당 유형의 마지막 항목 아래에 추가

**항목 유형별 입력 필드**:

| 유형 | 필드 | 필수 | 다중 허용 |
|------|------|------|---------|
| 이동(TRANSFER) | 교통편 종류, 시간 | 교통편 | ✓ |
| 관광(SIGHTSEEING) | 지역, 시간, 관광지명·내용 | 관광지명 | ✓ |
| 식사(MEAL) | 조식/중식/석식 구분, 식사 내용 | 식사 구분 | ✓ |
| 숙박(ACCOMMODATION) | 호텔명, 등급 | 호텔명 | ✓ |
| 기타(OTHER) | 자유 텍스트 | — | ✓ |

**드래그앤드롭 동작**:
- 같은 일차 내 순서 변경: 드래그핸들(`⋮`) 클릭 후 드래그
- 다른 일차로 이동: 일차 경계로 드래그 후 드롭
- 숙박 항목은 해당 일차 마지막 위치에 표시되도록 정렬
- 파일 파싱으로 들어온 동일 일차의 동일 호텔명은 중복 생성하지 않음

### FD-QUOTE-02 항목 테이블 컬럼 정의

| 컬럼 | 편집 | 설명 |
|------|------|------|
| 항목 | 자동 (일정표 연동) | 항공/숙박/관광/식사/차량/가이드/기타 |
| 지역 | 자동 (일정표 연동) | 일정표의 지역값 |
| 날짜 | 자동 (일정표 연동) | YYYY-MM-DD |
| 상세내역 | 자동 + 수동 수정 가능 | 일정표의 관광지명/호텔명 등 |
| 인원/개수 | 자동 (견적 개요 성인 인원) + 수동 | 자동 생성 기본값: 성인 인원수 |
| 단가 | **수동 입력** | 통화 선택 + 단가 (1인 또는 1개 기준) |
| 합계 | **자동 계산** | 인원/개수 × 단가 × 환율 |
| 건별합계 | **자동 계산** | 동일 항목 구분의 합계 (우측 병합셀) |

**참고 단가 표시**:
- 단가 입력칸 하단에 연회색으로 "참고: ₩181,000" 표시
- 클릭 시 해당 값으로 자동 채워짐 (확인 팝업 없음)

### FD-QUOTE-03 자동 계산 로직

```
항목 합계 = 인원/개수 × 단가 × 환율
건별합계 = Σ(동일 항목 구분의 합계)
경비 합계 = Σ(모든 건별합계)
VAT = 하나투어수익 × 0.1
총 합계 = 경비 합계 + 지상비수익 + 하나투어수익 + VAT
```

계산 갱신 시점: 단가, 통화, 환율, 인원, 수익 입력 변경 시 즉시 반영

### FD-QUOTE-04 총 경비 섹션

| 행 | 항목 | 입력 방식 |
|----|------|-----------|
| 1 | 항목소계 | 자동 |
| 2 | 지상비수익 | 협력사 입력, 1인당 금액 자동 표시 |
| 3 | 하나투어수익 | 수동 입력, 1인당 금액 자동 표시 |
| 4 | VAT | 자동 (하나투어수익 × 10%) |
| 5 | **TOTAL** | 자동 (항목소계 + 지상비수익 + 하나투어수익 + VAT) |

출력 문서에서는 `지상비수익`을 별도 행으로 노출하지 않고 `여행사수수료` 행에 `지상비수익 + 하나투어수익` 합산 금액을 표시한다. 견적 유효기간은 총 경비 섹션 아래에 우측 정렬 문구로 표시한다.

### FD-QUOTE-05 미리보기 모달

- **내용**: 실제 Excel 출력과 동일한 레이아웃 (read-only)

- **견적서 출력**: 상세내역 값은 좌측 정렬, 유효기간 문구는 총 경비 아래 우측 정렬

### FD-QUOTE-06 가격 표시 방식 (영업 담당자 전용)
- **위치**: 견적서 에디터 우상단 드롭다운
- **옵션**:
  1. **상세 표시**: 항목별 단가 모두 표시 (기본값)

### FD-VER-01 버전 생성 로직

```
function generateNextVersion(currentLatest: string): string {
  // v1.0 → v1.1
  // v1.9 → v1.10
  const [major, minor] = currentLatest.replace('v', '').split('.').map(Number)
  return `v${major}.${minor + 1}`
}

// 최초 생성 시: "v1.0"
// 협력사 첫 제출 시에만 v1.0, 이후는 항상 +0.1
```

### FD-EXCEL-03 파일명 생성 함수

```typescript
function generateExcelFilename(quote: Quote, type: 'itinerary' | 'cost'): string {
  const prefix = type === 'itinerary' ? '여행일정표' : '견적산출내역서'
  const date = format(new Date(), 'yyyy-MM-dd')
  return `${prefix}_${quote.title}_${quote.bidCode}_${quote.quoteCode}_${date}.xlsx`
}
// 예: 여행일정표_쿨인싱아웃4박_1209_QA0058262301_2026-03-18.xlsx
```

### 버전
```
GET  /api/quotes/:id/versions                          # 목록
GET  /api/quotes/:id/versions/:version                 # 특정 버전 조회
POST /api/quotes/:id/versions                          # 새 버전 저장
GET  /api/quotes/:id/versions/diff?from=v1.0&to=v1.1  # Diff
```

### Excel 출력
```
GET  /api/quotes/:id/export?type=itinerary&version=v1.2
GET  /api/quotes/:id/export?type=cost&version=v1.2
# 견적산출내역서에 인감 가이드 영역 자동 포함
```

### 상품 조회 (MCP 연동)
```
GET  /api/mcp/products/:productCode
     → MCP: 하나투어 상품 데이터 조회
     → { productName, region, duration, itinerary: DaySchedule[] }
```
